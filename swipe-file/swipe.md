### [2026-10-20] 用一句画面化的话说价值
- 来源：BaiFu 小红书《1K+Star的开源项目能给一个大学生带来什么》https://xhslink.cn/o/9ggO431DG4D
- 原文：可以从平台全量采集，再自动生成一份可以丢进汇报会的舆情简报
- 为什么打动我："丢进汇报会"一句话就让读者看到自己用它的场合，比讲多 Agent 架构有用得多。

### [2026-10-20] 读者只问三件事
- 来源：同上
- 原文：大多数人不是来帮你 code review 的，他们是来看：这个东西能不能帮我、能不能让我省时间、能不能让我装到逼。
- 为什么打动我：一句话把"功能"翻译成读者的三种收益，写任何介绍前都可以拿来自检。

### [2026-10-20] 用一张数据图当封面
- 来源：同上，封面是 BettaFish 的 Star History 曲线，配"意外出圈……比我想象的多得多"
- 原文：（图）几乎直角上翘的增长曲线 + 全文2761字｜阅读需9分钟
- 为什么打动我：曲线本身就是社会证明和悬念，读者想知道"拐点发生了什么"。

### [2026-10-20] 用产品口号给自己的成绩当包袱
- 来源：[@mirofish_ai](https://x.com/mirofish_ai) 2026-03-07 登顶 GitHub Trending 当天
- 原文：MiroFish: Predict Anything —— Including #1 on GitHub Trending.
- 为什么打动我：社会证明和品牌口号用同一句话说完，读者记住成绩的同时也记住了"预测万物"。

### [2026-10-20] Auday 首发帖开头：反问 + 你已经拥有
- 来源：[@auday_ai 首发帖](https://x.com/auday_ai/status/2106281145545719983)，约 210 万浏览；拆解见 [cases/2026-10-20-baifu-auday.md](../cases/2026-10-20-baifu-auday.md)
- 原文：The best AI recording hardware? You may already own it.
- 为什么打动我：先把自己放进读者熟悉的类别，再一句话推翻"要买新设备"的前提。拥挤市场里不拼"更好"，换一个新机制（Dunford 定类别 + Schwartz 第 3 阶段）。

### [2026-10-20] 用一句可验证的话拆掉最大顾虑
- 来源：同上 Auday 首发帖与 App Store 商店页
- 原文：We don't even have a backend server. / Your life doesn't need a place on our servers. We don't have any.
- 为什么打动我：全天录音最大的顾虑是隐私。它不说"我们重视隐私"，而是给出一个具体、反常识、可以自己验证的事实（Heath：Credible 里的 testable credentials）。

### [2026-10-20] 长文标题公式：时间 + 起点 + 具体结果 + 降调的大判断
- 来源：BaiFu 公众号「超级Vibe」[文章](https://mp.weixin.qq.com/s/l8QN_d41HXb_5nDFKHKK1g)
- 原文：七天时间，从零开始到把软件卖了三十万，我可能把 Apple Watch 变成了最好的 AI 录音硬件
- 为什么打动我：数字让结果具体，"从零开始"制造弱者叙事，"我可能"给大话降一点调，反而更可信。

### [2026-10-20] 把别人的质疑变成故事的前提
- 来源：同上文章开头
- 原文：也有人因此称我为"营销大师"，心里总有些不服气……这一次我想让 Auday 完全从零开始。
- 为什么打动我：一句话同时做了三件事：回应"营销包装"的指控、给自己加一个挑战（Challenge 情节）、让后面的数据显得更硬。

### [2026-10-20] 主动说出取舍的代价
- 来源：同上文章 3.1 节
- 原文：这样的取舍确实会减少很多收入，但对于这样一个产品，这个取舍值得。
- 为什么打动我：说出自己放弃了什么，比说自己有多好更可信。代价是最贵的信号。

### [2026-10-20] 独立开发者的营销两条
- 来源：BaiFu 公众号 [BettaFish 复盘文](https://mp.weixin.qq.com/s/UyYVjlBCvQRJI6B_MmZbsA)
- 原文：营销推广可以不多，但一定要提前准备好能让「别人帮你宣传」的素材……代码是冷的，故事是热的。
- 为什么打动我：他第一次投稿全部石沉大海，真正引爆的是一篇复盘故事。素材决定别人能不能替你转，故事决定别人想不想转。
