# Crossing the Chasm（Geoffrey Moore）

> 资料说明：版权书，未下载，未找到官方免费章节。本笔记基于对全书（第 3 版结构）的精读整理，只注章节，不注页码；书中具体公司案例随版本更新差异较大，引用前请对照手头版本。模块 README 指定读第 3–6 章，本笔记重点覆盖这几章。

## 30 秒读懂

- **一句话**：新产品从少数尝鲜者走向普通大众，中间有一道"鸿沟"，因为两群人买东西的理由完全不同。跨过去的办法是集中全部力量，先拿下一个很小但很具体的细分市场，在那里做到第一、提供完整方案，再一个个拿下相邻市场。
- **举个例子**：一款独立小游戏在开发者圈里被夸"有创意"，但普通玩家要看到身边的人在玩、有完整教程和稳定更新才肯下载。与其全网投放，不如先拿下一个具体社群（比如某个解谜游戏论坛），在那里做到人人知道，再扩到相邻的圈子（示例）。
- **什么时候用**：产品已有一些早期粉丝，却迟迟扩不到更多普通用户时。
- **可信度**：二手。版权书，未读原书，也没有找到官方免费章节；依据对第 3 版全书结构的了解，细节以原书为准。

## 核心论点

1. **技术采用生命周期（Technology Adoption Life Cycle）**：创新者（技术爱好者）→ 早期采用者（远见者 visionaries）→ 早期大众（实用主义者 pragmatists）→ 后期大众（保守者 conservatives）→ 落后者（怀疑者 skeptics）。相邻群体间都有缝隙，但**远见者和实用主义者之间的那道最深**，这就是"鸿沟"（第 1–2 章）。
2. **远见者 ≠ 实用主义者**：远见者买的是"跨越式变革"，愿意忍受不完整、愿意当第一个吃螃蟹的人，以此获得竞争优势；实用主义者买的是"渐进、可预期的改进"，要看**同行**用过、要市场领导者、要完整解决方案、要售后。远见者的推荐对实用主义者**几乎无效**，甚至是减分项——"他们是爱冒险的那群人"。
3. **实用主义者只听同类实用主义者的推荐**，而且彼此在同一行业/同一职能里互相打听。所以必须在一个**细分市场内**建立口碑密度，让推荐能在圈子里传开（第 3 章 D-Day 类比）。
4. **滩头阵地要小到能赢、大到有意义**：选一个你能在短期内成为**领导者**的细分市场，标准不是"最大"，而是"有强烈购买理由 + 你能交付完整产品 + 能当上第一 + 能带你进入下一个细分"（第 4 章 Target the Point of Attack）。
5. **完整产品（Whole Product）**：客户想买的不是你的核心产品，而是"保证我实现目标"的全部东西——集成、培训、服务、合作伙伴、标准。实用主义者对"缺一块"零容忍（第 5 章 Assemble the Invasion Force，借用 Levitt 的同心圆模型：通用产品 → 期望产品 → 扩展产品 → 潜在产品）。
6. **主动"创造竞争"**：实用主义者需要可比较的参照才敢买；如果你声称"没有竞争对手"，他们会认为没有市场。要同时指认"市场替代品"（预算原来花在哪）和"产品替代品"（与你技术相近的那家），把自己放在两者之间（第 6 章 Define the Battle）。
7. **定位 = 让产品"容易被买"**：Moore 把定位定义得非常务实——它是客户心中最重要的那个购买决定因素；在鸿沟期，定位的目标是让实用主义者觉得你是**某个细分里的领导者**。

## 框架 / 模型

### A. 定位陈述模板（第 6 章；02 模块 README 引用的版本即出自此）

> For **（目标客户——只写滩头阵地细分）**
> Who are dissatisfied with **（当前的市场替代品）**,
> Our product is a **（新产品类别）**
> That provides **（关键问题解决能力）**.
> Unlike **（产品替代品）**,
> We have assembled **（为你这个具体应用准备的完整产品关键要素）**.

配套 **电梯测试（Elevator Test）**：你能否在两句话内、在一趟电梯的时间里把它讲清楚？讲不清说明定位不成立，不是口才问题。

### B. 跨越鸿沟四步（第 4–7 章 = 一次登陆作战）

| 步骤 | 关键问题 | 输出 |
|---|---|---|
| 选定攻击点（Target the point of attack） | 哪一个细分的客户有"非买不可的理由"（compelling reason to buy）？ | 一个滩头阵地 + 基于场景的目标客户画像（target-customer scenarios） |
| 集结登陆部队（Assemble the invasion force） | 这群人需要的完整产品还缺什么？谁来补？ | 完整产品清单 + 合作伙伴 |
| 定义战场（Define the battle） | 我和谁比？市场替代品是谁？产品替代品是谁？ | 竞争定位 + 定位陈述 |
| 发起登陆（Launch the invasion） | 用什么渠道、什么定价进入这个细分？ | 渠道（早期多为直销）+ "市场领导者定价" |

### C. 保龄球道（Bowling Alley）

拿下第一个瓶（细分）后，选择**与它共享客户或共享应用场景**的下一个瓶：要么同一种应用卖给相邻行业，要么同一行业卖相邻应用——口碑和完整产品可以复用。

### D. 选滩头的检查清单（第 4 章思路归纳）

- 有明确的经济买家、能接触到；
- 有**非买不可**的理由（不解决就痛）；
- 你能在短期内（联合伙伴）交付完整产品；
- 没有已被牢固占据的领导者；
- 拿下后能撬动下一个细分；
- 与公司价值观/能力匹配。

## 案例与数据

- 书中的核心类比是 **1944 年诺曼底登陆**：盟军的目标是解放欧洲，但第一步只拿诺曼底的一段海滩，集中兵力、确保拿下，再向外推进——"不要试图一次占领整个欧洲"。
- 定位陈述模板常被拿来示范的写法（教学自拟，非书中原文）：For 在课外做竞品调研的学生社团，who 不满于手动复制网页、结果散落在聊天记录里，research-crawler is a 面向学生团队的调研抓取工具 that 把一个问题变成一份有出处的周报。Unlike 通用 AI 搜索，we 提供可复查的原始来源 + 团队共享模板。

## 适用边界与常见误用

- **原生场景是 B2B 高科技、"不连续创新"**（需要客户改变行为的产品）。对连续性改进（新款手机）、对 C 端病毒式产品，鸿沟可能很浅甚至不存在。
- **常见误用 1：滩头选太大**——"大学生"不是滩头，"伯克利做量化课题的本科研究助理"才是。检验法：你能叫出这个细分里 10 个具体的人吗？
- **常见误用 2：把定位陈述当广告语**。模板是内部对齐工具；对外的话术需要翻译成客户语言（04 文案模块）。
- **常见误用 3：用远见者的热情外推大众市场**——早期几个朋友夸你的作品，不代表下一圈陌生人会买。
- **与 Dunford 的关系**：Dunford 批评"填空式定位陈述"作为**寻找**定位的方法；Moore 的模板是**记录和检验**已选定滩头阵地后的定位——先用 Dunford 五步找，再用 Moore 模板写、用电梯测试检验。

## 出题素材

1. **（Oliver 真实场景）** research-crawler 的潜在用户里，谁是远见者、谁是实用主义者？各举 2 个真实的人或群体。远见者已经在用，实用主义者为什么还没用？缺的是"完整产品"的哪一块（教程？模板？案例？信任？）。
2. **滩头选择**：给出 3 个候选滩头（例：学生咨询社团 / 研究生做文献调研 / 小商家看竞品价格），按检查清单打分，选一个并说明"拿下它之后下一个保龄球瓶是谁"。
3. **定位陈述 + 电梯测试**：用 Moore 模板为你选的滩头写定位陈述，再压成两句话讲给一个不认识这个项目的人，记录他能否复述"给谁"和"与 X 有何不同"（衔接 02 练习 4）。
4. **创造竞争**：分别写出 research-crawler 的"市场替代品"（预算/时间原来花在哪）和"产品替代品"（技术相近的工具），说明你如何站在两者之间。
5. **反例题**：举一个"没有经历明显鸿沟"的产品，说明为什么 Moore 的模型在那里不适用。
