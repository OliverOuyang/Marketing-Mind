# Blue Ocean Strategy（Kim & Mauborgne）

> 资料说明：HBR 2004 年原文为付费墙（hbr.org 只显示开头一段：Cirque du Soleil 20 年做到 Ringling Bros. 用一百多年才达到的收入）。网络上的"课程 PDF"多为未授权转载，未采用。本笔记依据：① 作者官方网站 blueoceanstrategy.com 的免费页面（ERRC Grid、Strategy Canvas、Four Actions + ERRC 示例文章、Cirque du Soleil 案例页），原文已存私有目录，标【官网】；② 对 HBR 原文与同名书的扎实了解，标【文/书】，只注章节。

## 一句话

与其在拥挤的"红海"里按行业既定维度和对手比拼，不如**重新组合"买家价值要素"——同时砍成本（剔除、减少）和抬价值（提升、创造）——开出一片让竞争无关紧要的"蓝海"**。

## 核心论点

1. **红海 vs 蓝海**【文】：红海是已知市场空间，行业边界和竞争规则被接受，公司争夺既有需求，利润和增长前景越来越窄；蓝海是未知市场空间，需求被创造而不是被争夺。
2. **价值创新（value innovation）打破"差异化 vs 低成本"的取舍**【文；官网】：剔除和减少（Eliminate / Reduce）降低成本结构；提升和创造（Raise / Create）提高买家价值、创造新需求——两者同时做。（注意：这正面挑战了 Porter"在生产率前沿上必须取舍"的论断，教学时适合放在一起辩论。）
3. **看替代品与非顾客，而不只看竞争对手和现有顾客**【官网 Strategy Canvas 页】：战略画布"把关注点从竞争者转向替代品、从顾客转向行业的非顾客"。
4. **Cirque du Soleil 的处境原本极差**【官网案例页】：马戏业在衰退——明星演员议价力强、买方议价力强、其他娱乐形式挤压、孩子更想玩电子游戏、动物保护压力上升。按传统分析几乎没有增长潜力。它没有去抢马戏团的儿童观众，而是吸引**成人和企业客户**，愿意支付传统马戏数倍的价格；早期一部作品就叫《We Reinvent the Circus》。官网数据：作品被 300 多个城市、1.5 亿以上观众看过；不到 20 年达到 Ringling Bros. 一百多年才达到的收入水平。

## 框架 / 模型

### A. 战略画布（Strategy Canvas）【官网】

- 横轴：行业竞争和投入的各项**竞争要素**（价格、服务、功能……）；纵轴：买家在各要素上得到的**供给水平**。
- 每家公司在画布上连成一条**价值曲线**（value curve / strategic profile）。
- 红海的特征：大家的曲线长得几乎一样。
- 好的蓝海曲线有三个特征（书）：**聚焦**（focus）、**偏离**（divergence）、**一句有说服力的口号**（compelling tagline）。

### B. 四步动作框架 → ERRC 网格【官网】

| Eliminate 剔除 | Raise 提升 |
|---|---|
| 行业长期竞争、但已被视为理所当然的哪些要素应该**剔除**？ | 哪些要素应**远高于**行业标准？ |
| **Reduce 减少** | **Create 创造** |
| 哪些要素应**远低于**行业标准？（是否过度设计、过度服务？） | 哪些行业从未提供的要素应该**创造**？（把非顾客变成顾客） |

官网列出 ERRC 网格的四个好处：①逼你同时追求差异化与低成本；②立刻暴露"只加不减"的公司——成本上升、过度设计；③任何层级的经理都看得懂；④填满它很难，所以会逼你检查行业所有隐含假设。

### C. 官网 ERRC 示例

| | [yellow tail]（美国葡萄酒市场） | citizenM（酒店） |
|---|---|---|
| 剔除 | 酿酒术语、陈年/复杂度作为卖点 | 前台、礼宾、行李员、门童 |
| 减少 | 酒款数量（最初只有一红一白：Shiraz 和 Chardonnay） | 房间面积 |
| 提升 | （易于选择：简洁醒目的非传统酒标） | 睡眠质量（超大床、优质床品、隔音、淋浴） |
| 创造 | 易饮、易选、有趣冒险感——把喝啤酒/鸡尾酒的人变成葡萄酒顾客 | 自助入住机；多面手"ambassadors"取代前台员工 |
| 结果（官网） | 简化 SKU、加快库存周转 | 价格对三星客、评分领先；平均入住率 90%；每间房总成本比四星均值低约 40%，人员成本低约 50% |

### D. Cirque du Soleil 的 ERRC（据 HBR 原文/书，常见教学版本）【文/书】

剔除：明星演员、动物表演、过道零食叫卖、多环同时表演；减少：惊险刺激、幽默桥段；提升：独特场地；创造：主题与故事线、艺术化氛围、精致音乐与舞蹈、多部作品。——把"马戏的刺激"与"剧场的艺术"重组，成本反而下降（动物和明星最贵）。

## 适用边界与常见误用

- **幸存者偏差**：书中案例都是成功者，很多"自以为是蓝海"的新品类其实没有需求（Thiel 讲 PayPal 早期"Palm 上传钱"：没人做，但也没人需要）。蓝海必须通过"非顾客为什么不买"的证据来验证。
- **蓝海会变红**：模仿者迟早会来。蓝海带来的是先发窗口，护城河仍要靠 Porter 的活动契合或 Thiel 的网络效应/规模/品牌。
- **常见误用 1：只填 Raise/Create**。学生最爱"加功能"，官网特别警告这会抬高成本、过度设计。**规则：Eliminate + Reduce 至少要和 Raise + Create 一样认真。**
- **常见误用 2：把"蓝海"当口号**。没有画出行业的现状画布、没有列出竞争要素，就不是在用这套方法。
- **与定位的关系**：ERRC 是"切格子"的一种操作化方法——通过重新组合要素，创造一个新的类别/参照系（Dunford 的 create a new game）。

## 出题素材

1. **（Oliver 真实场景）** 为"学生找实习/找合作者的自我推销"这个行业画一张现状战略画布：横轴至少 6 个竞争要素（GPA、实习经历、简历排版、推荐信、作品集、海投数量……），画出"典型伯克利学生"的曲线。再用 ERRC 网格设计你的曲线——必须至少剔除 1 项、减少 1 项。
2. **research-crawler 的 ERRC**：对比"通用 AI 搜索"和"专业数据爬取服务"两条曲线，写出你的 ERRC 四格，并给出一句"聚焦、偏离、可传播"的口号。
3. **非顾客分析**：谁是"调研工具"的非顾客（知道但不用的人、拒绝用的人、从没想过的人）？各举一个具体人群，说出他们不用的原因。
4. **辩论题**：Porter 说"在生产率前沿上，差异化和低成本必须取舍"；Kim & Mauborgne 说价值创新能同时实现。用 citizenM 的数据为一方辩护，再找出这个案例里**仍然存在**的取舍（提示：它砍掉了什么、让谁不满意）。
5. **限制条件题**：预算为零，只能做"剔除"和"减少"——你的作品集/个人介绍能删掉什么，反而让你更突出？
