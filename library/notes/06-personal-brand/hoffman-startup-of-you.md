# The Start-up of You（把自己当创业公司经营）

> 来源说明：版权书，未下载全书（检索时网上能找到的全书 PDF 都是第三方挂的，不合法，未使用）。笔记依据：对全书框架的掌握，以及官方网站 startupofyou.com 的书籍介绍（2022 修订版列出的六项能力已核对）。章节按 2012 年版，修订版章节名基本一致；不标页码。

## 30 秒读懂

- **一句话**：把自己的职业当成一家创业公司来经营：永远在迭代，手上有 A、B、Z 三套计划，把人脉当作信息和机会的来源，并敢于承担算得清的风险。
- **举个例子**：Hoffman 第一次创业 SocialNet 没成，后来加入 PayPal 做高管，再创办 LinkedIn，书里用这条路径说明"A 不行就转向相邻的 B，一路积累人脉和声誉"。学生的 Plan Z 可以很具体，比如"申请失败就回学校做助教，同时继续做作品"（示例）。
- **什么时候用**：做职业规划、选实习方向，或者犹豫要不要冒一个险时。
- **可信度**：二手。版权书，未读原书；依据对全书框架的掌握，并核对了官网 startupofyou.com 的书籍介绍，细节以原书为准。

## 核心论点

1. **所有人都是创业者**（第 1 章 All Humans Are Entrepreneurs）：大公司终身雇佣的"自动扶梯"已经坏了。你是"你自己"这家公司的 CEO，要像创业公司一样敏捷、投资自己、建立网络、承担聪明的风险。核心心态是"永远测试版"：把自己看成永远未完成、可以持续迭代的产品。
2. **竞争优势来自三块拼图的交集**（第 2 章 Develop a Competitive Advantage）：
   - **资产（Assets）**：硬资产（钱、物、证书）和软资产（知识、技能、人脉、声誉）；
   - **志向与价值观（Aspirations & Values）**：你想要什么、在意什么；
   - **市场现实（Market Realities）**：别人愿意为什么付钱或给你机会。
   三者要一起看，并且会随时间变化。另一个提醒：选择一个**竞争没那么激烈**的"小池塘"，比在大池塘里和所有人拼同一个指标更容易建立优势。
3. **为适应而计划：ABZ 计划**（第 3 章 Plan to Adapt）：
   - **Plan A**：你现在在做的事，是当前竞争优势的落地方式；
   - **Plan B**：当 A 不行或出现更好机会时转向的方向，通常和 A 相邻（技能、行业或角色相近），会在执行 A 的过程中不断修订；
   - **Plan Z**：救生艇。万一一切失败，你确定能退守的底线（例如搬回父母家、去做一份稳定工作）。有了确定的 Z，你才敢在 A 和 B 上冒险。
   同时要兼顾"坚持"和"转向"：太早放弃和太晚转向都会出问题。
4. **一切都关乎人**（第 4 章 It's All About People）：职业是"我"到"我们"（I-to-We）。关系分两类：
   - **盟友（allies）**：少数深度信任、互相主动帮忙、分享机会的人；
   - **弱关系（weak ties）**：熟人。新信息和新机会常常来自弱关系，因为他们处在和你不同的圈子里（书中引用社会学家 Mark Granovetter 的"弱关系的力量"）。
   建立关系的方法：先给予，送"小而频繁的礼物"（一条有用的信息、一个引荐）；人脉的价值还来自二度、三度关系，通过引荐触达。
5. **突破性机会**（第 5 章 Breakout Opportunities）：机会不会自己来。要让自己处在机会流动的地方（行业中心、圈子、社群），主动加入或组织小组、多跑动（hustle），提高"偶然遇到好事"的概率，也就是"制造偶遇"。
6. **聪明地冒险**（第 6 章 Take Intelligent Risks）：人通常高估风险；而"不冒险"本身也是风险，长期来看可能更大。评估风险时问：最坏情况是什么？能否承受？可逆吗？还要明白**稳定和风险的关系可能是反的**：看起来稳定的工作，可能藏着更大的长期脆弱性（和 Taleb《反脆弱》呼应）。
7. **你认识谁，决定你知道什么**（第 7 章 Who You Know Is What You Know）：**网络情报（network intelligence）**指的是向人脉提问来获取书本和网络上没有的、带判断的信息。会问问题（问对人、问具体问题）是一种核心技能。

## 框架 / 模型

### A. 竞争优势三拼图（自评表）

| 拼图 | 我的现状（3 条） | 证据 | 和另外两块的重叠 |
|---|---|---|---|
| 资产：软（技能、知识、人脉、声誉） | | | |
| 资产：硬（钱、时间、工具） | | | |
| 志向与价值观 | | | |
| 市场现实（谁愿意为什么付费或给机会） | | | |

三块重叠最多的地方，就是当前的 Plan A 候选。

### B. ABZ 计划表

| 计划 | 内容 | 触发转换的信号 | 下次复盘日期 |
|---|---|---|---|
| A | | | |
| B（可多个） | | 什么信号出现时转向 B？ | |
| Z | 具体到能执行的退路（住哪、靠什么收入） | — | |

### C. 关系组合

```
盟友（少而深）：主动帮忙、分享机会、能为你担保
弱关系（多而浅）：新信息、新圈子的入口
二度/三度关系：通过引荐触达，引荐时要让对方容易帮你（写好可转发的一段话）
```

送"小礼物"的方式：转发一个对方会关心的链接、引荐一个对方需要的人、分享你的调研发现、给对方的作品写一份认真的反馈。

### D. 网络情报：提问清单

向人脉求信息时，问"一个具体判断"，不要问"有什么建议"。例："如果你是我，在 A 和 B 两个实习里选，你最看重哪一点？"

## 案例与数据

（具体细节以原书为准，以下只写框架性要点。）

- **Hoffman 自己的路径**：第一次创业 SocialNet 没有成功；后来加入 PayPal 任高管；再后来创办 LinkedIn。书中用这条路径说明"Plan A 失败后转向相邻的 Plan B，并且一路积累人脉和声誉资产"。
- **弱关系研究**：书中引用 Granovetter 的经典发现，人们找到新工作的信息往往来自弱关系，而不是亲密朋友。
- **ABZ 计划的 Plan Z**：作者强调 Z 应该具体、可执行，"搬回父母家并找一份能付账单的工作"这类退路，就足以让人敢在 A 上冒险。

## 适用边界与常见误用

1. **"人脉"被理解成"收名片"**：书的重点是盟友和真诚的给予。为了交换而社交，会被对方识破（可对照 Naval"商务社交是浪费时间"的批评）。
2. **Plan B 被写成"什么都可以"**：B 必须和 A 相邻、可执行、有触发信号，否则只是逃避。
3. **Plan Z 太模糊**：只写"总有办法"等于没有 Z，也就不会真正敢冒险。
4. **硅谷视角**：大量例子来自硅谷科技行业，对签证、家庭责任、身份限制较多的人，"聪明的风险"的计算要换参数（例如国际学生的工作许可）。提醒 Oliver 把自己的实际约束放进 Z 里。
5. **"永远测试版"可能变成永远不定**：迭代需要一个当前版本。要配合 06 模块"窄一点，才会被记住"，先选一个切入点。

## 出题素材

1. **Oliver 真实场景，ABZ 计划**：写出你接下来 12 个月的 A（例如"营销/增长方向实习 + 公开学习"）、至少一个 B（相邻方向，例如"以 research-crawler 为作品做调研/数据岗"）、一个具体的 Z。为 B 写出两个"触发信号"。导师追问：你的 Z 是否真的让你敢冒更大的险？如果不是，A 里可以加什么险？
2. **三拼图**：用竞争优势三拼图盘点自己，每块至少 3 条并附证据。找出一块"市场现实"里你最不确定的，设计一次"网络情报"提问去验证它（问谁、问什么一句话）。
3. **关系实验**：本周给 3 个弱关系各送一个"小礼物"（一条有用信息或一次引荐），不提任何请求。两周后记录：有几个人回应？有没有带来新信息？
4. **对比讨论**：Hoffman 说"一切都关乎人"，Naval 说"商务社交是浪费时间，做好东西对的人会找到你"。请 Oliver 给出自己的综合规则，并说明在"还没有作品"和"已经有作品"两个阶段，规则有什么不同。
5. **加约束**：只能联系 1 个人，就要为下一个机会拿到最大帮助。你选谁？发什么？（50 字以内，要让对方容易转发）
