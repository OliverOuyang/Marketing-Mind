# The Adweek Copywriting Handbook（文案训练手册）

> 来源说明：这本书受版权保护，本笔记只整理框架。Sugarman 在书中用编号的 "axiom" 来组织观点，**本笔记只引用最有名、各版本都一致的第 1、2 条**，其余观点不编号，也不写页码。"心理触发器"（psychological triggers）在不同版本里数量不同，大约 20 多到 30 个，这里只挑最常用的几个。module 04 的 README 推荐阅读前 8 章左右。

## 30 秒读懂

- **一句话**：广告里的每个元素，标题、图片、副标题，都只为一件事：让人读第一句。第一句只为让人读第二句。好文案像一条滑梯，读者一开始读就停不下来，一直滑到下单。
- **举个例子**：一个学生给教授发合作邮件，第一句写"我读了您上周的论文，手上有一组数据也许能帮上忙"，比"您好，我是某某大学大三学生"更能让人读第二句（示例）。
- **什么时候用**：写销售页、长邮件、README 这类需要读者一路读下去的文字时。
- **可信度**：二手。版权书，未读原书；只引用各版本一致的第 1、2 条公理，其余按书的公开介绍整理，细节以原书为准。

## 核心论点

1. **公理 1、2：每个元素都在为下一个元素服务**。
   - Axiom 1："All the elements in an advertisement are primarily designed to do one thing and one thing only: get the first sentence of the copy read."
   - Axiom 2："The sole purpose of the first sentence in an advertisement is to get the second sentence read."
   所以标题不负责"卖"，只负责"让人开始读"。
2. **第一句要短、要容易读**。Sugarman 常用的开头是 "It's easy."、"Lose weight." 这种三五个词的句子。读者读完第一句就已经"上了滑梯"。前几段也应该短，等动量建立起来再展开。
3. **Seeds of curiosity：在段尾埋钩子**。"But there's more."、"Let me explain."、"Here's why." 这类句子让读者跨过段落之间的断点。
4. **提出异议，再自己解答**。读者读到一半一定会产生疑问，比如"这么便宜会不会有问题？"。好文案会**比读者先一步**把疑问说出来，然后诚实地回答。这样做同时建立了可信度和"诚实"的形象。Sugarman 的 BluBlocker 太阳镜和 JS&A 电子产品邮购广告就大量使用这个手法。
5. **文案的长度由需要决定**。只要每一句都在推动读者往下读，长文案就成立；问题从来不是"太长"，而是"无聊"。这和 Hopkins 的 "The more you tell the more you sell" 一脉相承。
6. **先做大量准备，再写**。写之前要成为这个产品的专家，然后让信息在脑子里"孵化"（incubation），而不是对着空白页憋。这一点和 Halbert 的 "nugget notes" 加孵化，以及 Paul Graham 说的"想法 80% 来自动笔之后"可以互相印证。

## 框架 / 模型

**滑梯结构**（自上而下，每一层只为了让人进入下一层）：

```
标题  ──▶ 让人读副标题 / 第一句
副标题 ──▶ 让人读第一句
第一句（短！）──▶ 让人读第二句
前几段（短段落 + seeds of curiosity）──▶ 建立阅读动量
正文（产品故事 + 提出异议并解答 + 证明）──▶ 建立欲望与信任
结尾（逻辑理由 + 风险逆转 + 紧迫感 + 明确行动）──▶ 下单
```

**几个最常用的 psychological triggers**（版本不同，名称略有差异）：

| Trigger | 含义 | 文案里的样子 |
|---|---|---|
| Involvement / ownership | 让读者在脑中"用上"产品 | "想象你戴上它走出门……" |
| Honesty | 主动承认缺点 | "它不是最便宜的，原因是……" |
| Credibility | 具体细节和证明 | 数字、测试过程、真实用户 |
| Justify with logic | 人凭情感买，用逻辑说服自己 | 价格换算成每天几分钱，或和替代方案对比 |
| Satisfaction conviction | 超出常规的承诺 | "用 30 天不满意，退款，眼镜你留着" |
| Sense of urgency | 给马上行动的理由 | 期限、限量（必须真实） |
| Storytelling | 用故事带人进入 | "那年我在……" |
| Linking | 把新东西和熟悉的东西联系起来 | "它就像 X 的 Y 版" |

## 案例与数据

- **BluBlocker 太阳镜**：Sugarman 最有名的产品。广告的思路是让读者想象戴上眼镜后看到的世界，再配合"满意保证"降低尝试门槛。这是 involvement 加 satisfaction conviction 的组合。
- **JS&A 早期电子产品邮购**（计算器、数字手表等新奇电子产品）：新品类的读者有大量疑问，所以广告的大部分篇幅都在"提出异议并解答"。
- 书中还有大量 Sugarman 自己的整版广告供逐句拆解，是做 swipe file 的好材料（具体篇目以纸书为准）。

## 适用边界与常见误用

- **滑梯是为"主动阅读"场景设计的**，比如邮购整版广告、销售信、landing page、长邮件。在信息流里，滑梯只剩"标题加前两行"，后面的部分都要压缩。
- **"Seeds of curiosity" 用多了会变成标题党**。每个钩子之后必须真的给出东西，否则读者一旦失望就会失去信任。
- **紧迫感和"满意保证"必须真实可兑现**。Oliver 的开源项目写"限时免费"就是造假。
- **书偏重 B2C 直效营销**，对 B2B 或面向招聘官的文案（简历、cover letter）要改造：读者是来"筛选"你的，不是来"消遣"的，开头一句更要直接给结论。
- **不要把 triggers 当清单逐个打勾**。Sugarman 自己也强调，触发器只是在理解了产品和读者之后的工具。

## 出题素材

1. **（Oliver 真实场景）滑梯测试**：把 research-crawler 的 README 打印出来，在每一句后面标注"读者为什么会读下一句？"。凡是答不上来的地方就是滑梯断点，要修或者删。
2. **第一句训练**：给 skills-library 写 5 个不超过 5 个词的第一句，然后挑一个，说明它为什么能让人读第二句。
3. **提出异议**：写出 3 个陌生人看到 research-crawler 会冒出来的疑问，比如"合法吗？""会不会被封？""比 Scrapy 好在哪？"。把它们写进文案，并诚实回答。追问：哪一个异议你回答不了？那就是产品或定位的问题，不是文案的问题（对应 02、03 模块）。
4. **Satisfaction conviction 设计**：Oliver 想接一个付费小单，比如帮人做一次数据抓取。请他设计一个"超出常规"但他真的能兑现的保证。
5. **加难度**：把一封 300 字的合作邀约压到 80 字，同时保留滑梯结构（钩子、理由、行动）。

## 对应模块与练习

- **04 练习 1（结构识别）**：用"滑梯"来拆 swipe file 里每一段的作用。
- **04 练习 2（三版对比 AIDA/PAS/BAB）**：滑梯可以看作 AIDA 的"微观版"，每一句都在做 Attention → Interest 的传递。
- **04 练习 3（标题训练）**：Axiom 1 重新定义了标题的任务。
- **04 练习 6（真实发布）**：发布前做一遍"提出异议"的自检。
- **03 练习 3（报价五件套）**：satisfaction conviction 就是风险逆转。
