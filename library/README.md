# 资料库（library/）

导师出题、点评、举例的依据都从这里来。原则：**只收合法可得的资料，读透再收**。

## 目录

| 位置 | 放什么 |
|---|---|
| `INDEX.md` | 总索引：按模块列出每份资料、来源等级、一句话和笔记链接。由 `scripts/build_index.py` 生成，不要手改 |
| `notes/<模块号>-<主题>/<slug>.md` | 精读笔记（每份资料一篇），是本库的核心 |
| `texts/` | 可以合法再分发的全文：公版（public domain）、CC 协议、作者明确允许转载的 |

## 版权取舍

本仓库是**公开仓库**，所以：

- **公版 / CC / 作者允许转载** → 全文存进 `texts/`，笔记里标 `access: 全文（仓库）`。
- **免费可读但有版权的文章、论文**（作者博客、HBR 免费文、开放获取论文的出版社 PDF 等）→ 仓库里只放链接 + 精读笔记 + 短引用；下载的原文存在项目私有共享文件夹 `/mnt/project-files/marketing-mind/library-raw/`（不公开，仅供导师备课时回查），笔记里标 `access: 原文已下载（私有）`。
- **免费在线、但没存私有副本的文章** → 仓库里只放链接 + 精读笔记 + 短引用，笔记里标 `access: 仅笔记（免费原文在线，未存私有副本）`。
- **受版权保护的书** → 不下载盗版 PDF。仓库里放"核心框架精读笔记 + 购买/借阅链接"，若作者或出版社公开了官方试读章节、作者免费演讲/文章，一并收为辅助资料。笔记里标 `access: 仅笔记（版权书）`。

## 精读笔记模板

```markdown
---
title: 资料标题（原文）
title_zh: 中文名（如有）
author: 作者
year: 年份
type: book | paper | article | essay | talk | report | ebook
modules: ["00", "02"]          # 对应模块
priority: 必读 | 推荐 | 选读
access: 全文（仓库） | 原文已下载（私有） | 仅笔记（免费原文在线，未存私有副本） | 仅笔记（版权书） | 仅笔记（付费墙）
source_url: 官方/合法来源链接
local_file: texts/xxx.md 或 library-raw/xxx.pdf（没有就留空）
source_level: 一手 | 一手（官方节选/摘要） | 二手   # 依据的是作者本人的材料，还是别人的转述
verified: 已读原文 | 部分原文 | 未读原文
updated: YYYY-MM-DD
---

# 标题

## 30 秒读懂

- **一句话**：大白话讲最重要的一个观点。
- **举个例子**：2–3 句；自编示例句末标"（示例）"。
- **什么时候用**：一句。
- **可信度**：一手/二手 + 依据说明。

## 核心论点
3–6 条，每条带理由或证据。

## 框架 / 模型
能直接拿来教学的形式（步骤、公式、清单、2×2）。

## 案例与数据
可直接用于教学的具体案例、实验、数字，注明出处位置（章节/页码/段落）。

## 适用边界与常见误用
什么时候失效、学生最容易用错的地方。

## 出题素材
3–5 道可以直接拿来用的练习题或追问（至少一道落到 Oliver 自己的真实场景）。

## 对应模块与练习
链接到 `modules/` 里具体的练习题号。

## 原文短引
≤ 3 条短引用（每条一两句），附位置。

## 获取方式
购买 / 借阅 / 免费阅读链接。
```
