# 为什么做这个项目：作者心路

> 这是写项目介绍文章的素材，记录 Oliver 做 Marketing Mind 的起因。按他本人原话整理（2026-10-20），只调整了标点和分段，没有补写他没说过的经历和情绪。之后写文章时，凡是要展开的细节（具体是哪个游戏、哪天、看到了什么数字），都要先找他确认再写。

## 原话

> 我自己有开发自己的小游戏，但分发非常难没人看，然后又看到小王子的精致以及大规模传播，以及宣发非常成功，所以想潜心把营销这一块吃透。然后现在又看到 BaiFu 的营销很成功，所以结合书籍、文章和例子，做了营销知识库 + skill，帮忙写出高质量文章。

> 我现在愈发觉得会写文章、会做内容真的很重要。

> 营销比埋头苦干重要多了。（2026-10-20，项目对话）

## 时间线（按原话整理）

| 阶段 | 发生了什么 | 当时的认识 |
|---|---|---|
| 1. 做游戏 | 自己开发小游戏 | 分发非常难，没人看 |
| 2. 看到小王子 | 看到 Sac 的网页 3D 游戏《小王子：星辰之旅》作品精致，并且大规模传播、宣发非常成功 | 决定潜心把营销吃透 |
| 3. 看到 BaiFu | 看到独立开发者 BaiFu 的营销很成功 | 营销是可以拆、可以学的 |
| 4. 做 Marketing Mind | 结合书籍、文章和案例，做了营销知识库 + skill | 目标是帮忙写出高质量的文章和内容 |
| 5. 开源 | 决定把整个项目开源，自己开始审核内容和 skill | 会写文章、会做内容真的很重要 |

## 待 Oliver 确认

- **时间顺序**：仓库是 2026-10-11 建的，而《小王子：星辰之旅》是 2026-10-13 发布的（见[案例](../cases/2026-10-20-sac-little-prince.md)）。原话里"看到小王子 → 想潜心吃透营销"的顺序，写文章前需要确认：是更早看到过 Sac 的其他作品，还是建仓库之后小王子让他下定决心。
