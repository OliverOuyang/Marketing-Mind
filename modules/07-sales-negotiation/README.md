# 07 · 销售与谈判

> 核心问题：怎么把兴趣推进成行动？怎么在谈判中拿到好结果，同时保住关系？

> 状态：骨架。学到这里时和导师一起补全细节。

## 学习目标

1. 理解销售的本质是"帮对方做决定"，而不是说服对方。
2. 掌握一套基本的销售对话结构（发现需求 → 呈现价值 → 处理异议 → 推进下一步）。
3. 能识别并处理最常见的几类异议（价格、时机、信任、决策权）。
4. 掌握谈判的核心概念：BATNA、锚定、利益而非立场、战术共情。

## 核心框架

### SPIN 提问（Neil Rackham）

| 类型 | 目的 | 例子 |
|---|---|---|
| Situation 背景 | 了解现状 | "你们现在内容是谁在做？" |
| Problem 难点 | 找到问题 | "这样做最头疼的是什么？" |
| Implication 暗示 | 放大后果 | "如果这个问题一直不解决，对下季度会有什么影响？" |
| Need-payoff 需求-效益 | 让对方说出价值 | "如果能解决，对你意味着什么？" |

### 原则谈判（《Getting to Yes》）

1. 把人和问题分开。
2. 关注利益，而不是立场。
3. 创造双赢选项。
4. 坚持客观标准。
5. 先想清楚你的 **BATNA**（谈不成时的最佳替代方案）。BATNA 越好，底气越足。

### 战术共情（Chris Voss《掌控谈话》）

- **标签**："听起来你很担心交付时间……"
- **镜像**：重复对方最后几个关键词，引导对方多说。
- **校准式问题**："我们要怎么做才能……？"让对方帮你解决问题。
- 追求"你说得对"，而不是"好的"。

### 推进的最小单位

每次对话结束都要有一个**明确的下一步**（时间、人、事）。没有下一步的对话等于没有推进。

## 推荐阅读

- Chris Voss《掌控谈话》（Never Split the Difference）
- Roger Fisher 等《谈判力》（Getting to Yes）
- Neil Rackham《销售巨人》（SPIN Selling）

## 练习题

1. 和导师做角色扮演：导师扮演一个犹豫的客户/面试官，你用 SPIN 推进对话。
2. 列出你最常遇到的 5 个"拒绝"，为每个写出 2 种回应方式。
3. 下一次真实的协商（薪资、价格、合作条件、甚至二手交易），事前写 BATNA 和目标，事后复盘。
4. 镜像练习：在 3 次日常对话里刻意使用"镜像"和"标签"，记录效果。
