# 07 · 销售与谈判

> 核心问题：怎么把兴趣推进成行动？怎么在谈判中拿到好结果，同时保住关系？

## 学习目标

学完这个模块，你应该能：

1. 理解销售的本质是"帮对方做出一个好决定"，而不是说服对方。
2. 用一套销售对话结构（发现需求 → 呈现价值 → 处理异议 → 推进下一步）完成一次完整对话。
3. 识别并处理最常见的四类异议：价格、时机、信任、决策权。
4. 掌握谈判的核心概念：BATNA、保留价、锚定、利益而非立场、战术共情。

## 核心概念

### 1. 销售是诊断，不是推销

好医生不会一见面就开药。好的销售也一样：**先诊断，再开方**。你在问问题时，对方在思考自己的问题；你在介绍产品时，对方在想怎么拒绝你。

一个实用比例：对话中**对方说的时间应该多于你**。

### 2. 人们讨厌"被推销"，但喜欢"买到好东西"

阻力往往不是来自产品，而是来自压力感。降低压力的做法：

- 给对方说"不"的空间："如果不合适也完全没问题，我想先了解一下你们的情况。"
- 聊对方的问题，而不是你的方案（01 模块的 Mom Test 在这里同样适用）。
- 让对方自己说出价值，比你说一百遍更有说服力。

### 3. 异议是信号，不是拒绝

"太贵了"往往意味着"我还没看到足够的价值"或"我不确定能不能成"。处理异议的第一步不是反驳，而是**弄清楚异议背后真正的担心**。

### 4. 每次对话都要有下一步

没有明确下一步的对话等于没有推进。"有空再聊""我考虑一下"不是下一步。下一步要有**时间、人、事**："周四下午 3 点，我把方案发给你和你的合伙人，周五我们 15 分钟过一遍。"

### 5. 谈判的底气来自你的替代方案

谈判中最有力量的不是口才，而是**你有没有别的选择**。手上有两个 offer 的人和只有一个 offer 的人，在薪资谈判里的底气完全不同。所以谈判的功夫很多在谈判桌之外：提前给自己创造选项。

## 核心框架

### 销售对话四步

| 步骤 | 目的 | 关键动作 |
|---|---|---|
| 1. 发现需求 | 搞清对方的处境、问题、目标 | 用 SPIN 提问，少说多听 |
| 2. 呈现价值 | 把你的方案和对方说出的问题连起来 | 用对方的原话复述问题，再讲你怎么解决 |
| 3. 处理异议 | 弄清并化解真正的担心 | 先确认、再追问、再回应 |
| 4. 推进下一步 | 拿到一个具体承诺 | 时间 + 人 + 事 |

### SPIN 提问（Neil Rackham）

| 类型 | 目的 | 例子（向小商家推销视频服务） | 例子（面试） |
|---|---|---|---|
| Situation 背景 | 了解现状 | "你们现在内容是谁在做？" | "这个岗位目前团队最主要的目标是什么？" |
| Problem 难点 | 找到问题 | "这样做最头疼的是什么？" | "这个目标里最难的部分是什么？" |
| Implication 暗示 | 放大后果 | "如果一直这样，对下个月客流有什么影响？" | "如果这个问题拖到下季度，会影响什么？" |
| Need-payoff 需求-效益 | 让对方说出价值 | "如果每周能稳定出 3 条视频，对你意味着什么？" | "如果新人能在第一个月就上手这块，对团队帮助大吗？" |

背景问题少问（可以提前做功课），暗示和需求-效益问题是关键。

### 异议处理：LAER

| 步骤 | 做法 | 例子 |
|---|---|---|
| Listen 倾听 | 让对方说完，不打断 | |
| Acknowledge 确认 | 承认这个顾虑合理 | "理解，预算确实要花在刀刃上。" |
| Explore 追问 | 弄清背后的真正担心 | "您说贵，是和什么比较呢？还是担心效果不确定？" |
| Respond 回应 | 针对真正的担心回应 | 担心效果 → 给案例或保证；比较价格 → 拆价值 |

### 四类常见异议

| 异议 | 背后常见的担心 | 回应方向 |
|---|---|---|
| 价格："太贵了" | 价值没看到、风险太高 | 回到价值方程（03 模块）：加确定性、加保证、分阶段 |
| 时机："现在不是时候" | 优先级不够、痛不够 | 用暗示问题看"不做的代价"，或约一个具体的未来时间点 |
| 信任："我再看看" | 不确定你能做到 | 案例、试用、小单起步 |
| 决策权："我得问一下老板" | 自己做不了主，或在找借口 | "你觉得老板最关心哪一点？我帮你准备一份一页纸" |

### 原则谈判（Fisher & Ury《Getting to Yes》）

1. **把人和问题分开**：对事不对人，关系和条款分开处理。
2. **关注利益，而不是立场**：立场是"我要 2 万"，利益是"我需要覆盖房租并感觉被认可"。利益往往有多种满足方式。
3. **创造双赢选项**：在分蛋糕之前先把蛋糕做大（例如薪资谈不动，就谈签字费、远程天数、培训预算、转正时间）。
4. **坚持客观标准**：用市场数据、行业惯例，而不是"我觉得"。
5. **先想清楚 BATNA**：谈不成时你的最佳替代方案是什么？

### 谈判前的准备表

```
我的目标：理想结果是 ___
我的 BATNA：谈不成我会 ___
我的保留价：低于/高于 ___ 我就走
对方的 BATNA（推测）：___
对方真正在意的利益（推测）：___
可交换的筹码（对我成本低、对对方价值高）：___
我的开价（锚点）：___，理由是 ___
```

### 战术共情（Chris Voss《掌控谈话》）

- **标签**："听起来你很担心交付时间……"说出对方的情绪，情绪就会降温。
- **镜像**：重复对方最后 1–3 个关键词，用疑问的语气，引导对方多说。
- **校准式问题**：用"怎么"和"什么"开头："我们要怎么做才能让这个预算行得通？"让对方帮你解决问题。
- 追求"你说得对"（对方感到被理解），而不是"好的"（往往只是敷衍）。

### 锚定：先开价还是后开价？

- 你**有信息优势**（知道市场价）时，先开价，把锚抛在有利的位置，并附上理由。
- 你**信息不足**时，先让对方开价，避免把自己锚低。
- 开价要有理由："根据 ___ 的数据，同类岗位在 ___ 到 ___ 之间，结合我的 ___，我期望 ___。"

## 案例速读

- **Chris Voss 的人质谈判**：FBI 谈判专家把"让对方说'你说得对'"作为突破口，同样适用于商业和日常谈判。
- **实习薪资谈判**：一个学生拿到 offer 后没有直接要更多钱，而是问"在这个薪资范围外，有没有可能在 ___ 方面调整？"最后拿到了提前转正评估和额外的学习预算。关注利益，不卡在立场。
- **二手交易**：卖家标价 3000，买家直接说"2000 卖吗"容易谈崩；更好的做法是先问"这个用了多久？有什么毛病吗？"（发现需求），再基于对方的出售原因（急着搬家）提一个"今天就能带走"的报价。

## 推荐阅读

- Chris Voss《掌控谈话》（Never Split the Difference）：最实用的谈判书，读第 2–4 章（镜像、标签、"不"）。
- Roger Fisher 等《谈判力》（Getting to Yes）：原则谈判和 BATNA 的原典。
- Neil Rackham《销售巨人》（SPIN Selling）：读第 4–5 章就够。
- Bob Moesta《Demand-Side Sales 101》：选读，站在买方视角看销售，和 01 模块的 JTBD 连起来。

## 练习题

1. **角色扮演**：和导师做角色扮演，导师扮演一个犹豫的客户/面试官，你用 SPIN 推进对话，结束时必须拿到一个具体的下一步。
   - 加难度：导师扮演"预算只有你报价一半"的客户，你不能降价。
2. **异议手册**：列出你最常遇到的 5 个"拒绝"，为每个写出用 LAER 处理的两种回应方式。
3. **真实谈判**：下一次真实的协商（薪资、价格、合作条件、甚至二手交易），事前填谈判准备表，事后用复盘模板记录。
4. **镜像与标签**：在 3 次日常对话里刻意使用"镜像"和"标签"，记录对方的反应和你的感受。
5. **扩大 BATNA**：为你目前最想要的一个机会，列出 3 个能提升你 BATNA 的具体行动，并完成其中一个。
