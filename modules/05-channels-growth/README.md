# 05 · 渠道与增长

> 核心问题：我的人在哪里？怎么用最低成本让他们看到我，并让传播自己发生？

> 状态：骨架。学到这里时和导师一起补全细节。

## 学习目标

1. 用"牛眼框架"系统地筛选和测试渠道，而不是凭感觉。
2. 理解 AARRR 漏斗，能找出一个增长过程中最该优化的环节。
3. 理解口碑传播的驱动因素，设计"值得被分享"的东西。
4. 区分三类媒体：自有、付费、赢得（Owned / Paid / Earned）。

## 核心框架

### 牛眼框架（Bullseye，《Traction》）

1. **外环**：头脑风暴全部 19 类渠道（内容、SEO、社区、社媒、合作、线下活动、销售、PR……）。
2. **中环**：挑 3 个最有希望的，每个用小成本实验测试。
3. **内环**：集中火力在跑通的那 1 个上。

### AARRR 海盗指标

获取（Acquisition）→ 激活（Activation）→ 留存（Retention）→ 推荐（Referral）→ 收入（Revenue）

先找到漏得最厉害的那一环，再动手。

### 口碑六原则 STEPPS（Jonah Berger《疯传》）

社交货币、诱因、情绪、公共性、实用价值、故事。

### 三类媒体

| 类型 | 例子 | 特点 |
|---|---|---|
| 自有（Owned） | 个人网站、公众号、邮件列表 | 可控、积累慢、长期复利 |
| 付费（Paid） | 广告投放 | 快、可量化、停了就没了 |
| 赢得（Earned） | 被转发、被报道、被推荐 | 最可信、最难控制 |

## 推荐阅读

- Gabriel Weinberg & Justin Mares《Traction》
- Jonah Berger《疯传》（Contagious）
- Sean Ellis《增长黑客》（Hacking Growth）

## 练习题

1. 为你的一个项目做牛眼框架外环：列出全部渠道类别，每类写一个具体打法。
2. 选 3 个渠道，各设计一个不超过一周、成本几乎为零的实验，写出要看什么指标。
3. 用 STEPPS 拆解一个你最近转发过的东西。
4. 画出你某个项目的 AARRR 漏斗，估算每一环的转化率，指出最大漏点。

## 通关标准

- [ ] 至少跑完一个真实的渠道实验，并有数据记录和结论。
- [ ] 能为任一产品说出"最可能跑通的前 3 个渠道"并给出理由。
