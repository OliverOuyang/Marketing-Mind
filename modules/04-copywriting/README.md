# 04 · 文案与说服

> 核心问题：怎么写、怎么说，才能让人看完就想行动？

> 状态：骨架。学到这里时和导师一起补全细节。

## 学习目标

1. 掌握 3 个最常用的文案结构（AIDA、PAS、Before-After-Bridge）。
2. 理解 Cialdini 的 7 个影响力原则，并能识别它们在广告里的运用。
3. 写出让人想点开的标题和开头。
4. 学会"讲故事"：用故事而不是形容词来证明价值。

## 核心框架

### 文案结构

| 结构 | 步骤 | 适合 |
|---|---|---|
| AIDA | 注意 → 兴趣 → 欲望 → 行动 | 广告、落地页 |
| PAS | 问题 → 放大痛苦 → 解决方案 | 痛点明显的产品、短文案 |
| BAB | 之前的处境 → 之后的样子 → 我是那座桥 | 个人服务、案例展示 |

### 影响力七原则（Cialdini《影响力》）

互惠、承诺与一致、社会认同、喜好、权威、稀缺、统一性（我们是一伙的）。

### 让信息有粘性：SUCCESs（Heath 兄弟《让创意更有粘性》）

简单（Simple）、意外（Unexpected）、具体（Concrete）、可信（Credible）、情感（Emotional）、故事（Stories）。

### 几条基本功

- 写给一个具体的人，而不是"大家"。
- 用具体数字和细节替代形容词："很快" → "48 小时交付"。
- 一段文案只要一个行动（CTA）。
- 用用户的原话（来自 01 模块的差评考古）。

## 推荐阅读

- Robert Cialdini《影响力》（Influence）
- Chip & Dan Heath《让创意更有粘性》（Made to Stick）
- Joseph Sugarman《文案训练手册》（The Adweek Copywriting Handbook）
- Donald Miller《你的顾客需要一个好故事》（Building a StoryBrand）

## 练习题

1. 从 `swipe-file/` 里挑 5 条好文案，标注各自用了哪个结构和哪些影响力原则。
2. 为同一个产品分别用 AIDA、PAS、BAB 写三版 100 字文案，让导师点评。
3. 标题训练：同一篇内容写 20 个标题，选出最好的 3 个，说明理由。
4. 把你的自我介绍改写成一个 60 秒的故事（BAB 结构）。

## 通关标准

- [ ] 能在任一广告中识别出至少 2 个影响力原则。
- [ ] 写出一段真实发布的文案（帖子、简介、邮件），并记录数据或反馈。
