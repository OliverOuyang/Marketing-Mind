# 06 · 个人品牌

> 核心问题：怎么把"我"变成一个值得被记住、被信任、被推荐的品牌？

## 学习目标

学完这个模块，你应该能：

1. 把 00–05 模块的方法完整用在"自己"身上：自我定位、价值主张、文案、渠道。
2. 写好几个关键"门面"：一句话介绍、30 秒电梯演讲、个人简介、作品集。
3. 建立"公开学习/公开创作"的习惯，让机会主动找来。
4. 用"内容金字塔"规划持续输出，并用数据判断什么内容有效。

## 核心概念

### 1. 你已经有个人品牌了，只是没在管理它

个人品牌就是**别人在你不在场时怎么说你**（这句话常被归于 Jeff Bezos）。不管你做不做，别人都会给你贴标签。区别只在于这个标签是你主动塑造的，还是随机形成的。

### 2. 个人品牌 = 定位 × 证据 × 曝光

三者是**相乘**关系，任何一项为零，结果就是零。

| 要素 | 意思 | 常见问题 |
|---|---|---|
| 定位 | 别人提到 ___ 时，会想到你（来自 02 模块） | 什么都会一点，别人记不住 |
| 证据 | 作品、案例、数据、推荐语 | 只有自我描述，没有可验证的东西 |
| 曝光 | 在对的人看得到的地方持续出现 | 作品很好，但只存在自己硬盘里 |

### 3. 窄一点，才会被记住

"我是一个对设计、产品、运营都感兴趣的学生"等于没说。"我专门研究大学生副业的增长打法，已经拆了 30 个案例"会被记住，也会被转介绍。

窄不等于永远窄。定位是**切入点**，不是终身标签。先在一个小领域被记住，再扩展。

### 4. 公开创作：把学习过程变成作品

Austin Kleon《秀出你的工作》的核心：

- 你不需要是专家。**分享你正在学的过程**，对比你落后一步的人就有价值。
- 记录比表演容易坚持：笔记、进度、失败、灵感来源都可以分享。
- **教别人是最好的营销**：把你学会的东西讲清楚，本身就是能力证明。

这个仓库本身就是一个现成的公开创作素材库：每一次练习、案例拆解、复盘，稍作整理就是一条内容。

### 5. 信任是复利

一次惊艳的表现带来关注，但持续可靠地出现才带来信任。很多机会（内推、合作、邀约）都来自"我一直看你在做这件事"。

## 核心框架

### 必备"门面"清单

| 门面 | 要求 | 检验方法 |
|---|---|---|
| 一句话介绍 | 20 字以内，说清"我帮谁做什么" | 陌生人听完能复述 |
| 30 秒电梯演讲 | 我是谁 → 我在做什么（附一个证据）→ 我在找什么 | 对方会追问一个具体问题 |
| 各平台简介 | 统一定位，按平台调语气；包含一个证据和一个联系方式 | 截图给 3 个朋友看，问"他是做什么的" |
| 作品集/案例页 | 3–5 个最好的作品，每个讲清问题、做法、结果 | 对方 2 分钟内能看懂你的水平 |
| 推荐语/可验证成果 | 3 条以上，最好有具体结果 | 有名有姓、可追溯 |

### 电梯演讲结构

```
我是 ___（身份/定位，一句话）。
最近在做 ___（一个具体项目），已经 ___（一个具体成果/数字）。
我正在找 ___（具体的机会/人/帮助），如果你认识 ___，很想聊聊。
```

最后一句最常被漏掉：**不说你要什么，别人就没法帮你**。

### 内容金字塔

| 层级 | 内容 | 频率 | 例子（从本仓库拆） |
|---|---|---|---|
| 基石 | 深度长文、完整作品、项目复盘 | 每月 1–2 篇 | 09 模块的综合实战复盘 |
| 支柱 | 从基石拆出的观点、清单、案例 | 每周 2–3 条 | 一个案例拆解、一份框架清单 |
| 碎片 | 日常想法、进度、互动 | 随时 | 今天学到的一个概念 |

先有基石，再拆支柱和碎片，比每天想"今天发什么"轻松得多。

### 个人品牌审计（打分 1–5）

| 维度 | 问题 | 分数 |
|---|---|---|
| 定位清晰度 | 看完我的主页，陌生人能一句话说出我是做什么的吗？ | |
| 证据强度 | 有可验证的作品/数据/推荐吗？ | |
| 一致性 | 各平台说的是同一个"我"吗？ | |
| 曝光 | 目标人群能在他们常去的地方看到我吗？ | |
| 可联系性 | 想找我的人知道怎么找、为什么找吗？ | |

## 案例速读

- **Ali Abdaal**：医学生时期在 YouTube 分享学习方法，定位极窄（"医学生的高效学习"），证据就是自己的成绩和视频本身。后来扩展到生产力领域。
- **Pieter Levels**：在 Twitter 上公开"一年做 12 个产品"，过程、收入、失败全公开。公开本身就是渠道，Nomad List 和 Remote OK 都借此起步。
- **Julia Evans**：把自己学编程过程中的笔记画成小漫画（Wizard Zines），"教别人"让她成为技术圈知名的讲解者。
- **求职场景**：一个学生在求职前 3 个月每周发一篇"拆解一家目标公司的增长打法"，面试时面试官说"我看过你写我们的那篇"。

## 推荐阅读

- Austin Kleon《秀出你的工作》（Show Your Work!）：很薄，一下午读完，立刻能动手。
- Reid Hoffman《至关重要的关系》（The Startup of You）：把自己当创业公司经营。
- Eric Jorgenson《纳瓦尔宝典》（The Almanack of Naval Ravikant）：读"财富"部分关于杠杆和"产品化自己"。
- Paul Jarvis《一人企业》（Company of One）：选读，关于小而美的个人事业。

## 练习题

1. **门面初稿**：写出你的一句话介绍和 30 秒电梯演讲，交给导师点评。
   - 加难度：一句话介绍压缩到 12 个字。
2. **实测**：在 3 个不同场合（课堂、社交活动、线上私聊）实际使用电梯演讲，记录对方的第一反应和追问。
3. **品牌审计**：用上面的审计表给你现在的公开资料（社交主页、简历、作品集）打分，列出 3 个最该改的地方，改完前后对比截图。
4. **公开学习 2 周**：选一个平台，连续 2 周公开分享这个仓库的学习过程（每周至少 3 条），记录数据，复盘哪类内容效果最好。
5. **拆解三人**：找 3 个你欣赏的个人品牌，拆解他们的定位、证据和内容节奏，写进 `cases/`。

## 通关标准

- [ ] 所有"门面"写完，且至少有一位陌生人能准确复述你是做什么的。
- [ ] 持续输出至少 4 周，有数据记录。
- [ ] 至少有一次因为内容带来的真实机会（私信、合作、邀约、内推）。
