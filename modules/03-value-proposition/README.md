# 03 · 价值主张与报价

> 核心问题：怎么让"选我"成为一笔显而易见的好交易？

> 状态：骨架。学到这里时和导师一起补全细节。

## 学习目标

1. 用价值主张画布把"用户痛点/收益"和"我的产品/能力"一一对上。
2. 理解价值方程，知道从哪四个方向提升一个报价的吸引力。
3. 能设计一个让人难以拒绝的报价（Offer），包括定价、保证、附加价值和稀缺性。
4. 知道怎么给自己的时间和技能定价。

## 核心框架

### 价值主张画布（Strategyzer）

| 用户侧 | 我方侧 |
|---|---|
| 任务（Jobs）：要完成什么 | 产品与服务：我提供什么 |
| 痛点（Pains）：阻碍和风险 | 止痛药（Pain relievers）：怎么消除痛点 |
| 收益（Gains）：想要的结果 | 增益器（Gain creators）：怎么创造收益 |

**契合** = 我方侧的每一项都能精确对上用户侧最重要的痛点和收益。

### 价值方程（Alex Hormozi《$100M Offers》）

```
感知价值 = （梦想结果 × 实现可能性）÷（等待时间 × 付出努力）
```

提升报价吸引力的四个方向：让结果更诱人、让成功更可信（案例、保证）、让结果来得更快、让对方更省力。

### 定价的几个关键认知

- 价格是定位的一部分：低价会告诉对方"我不太值钱"。
- 锚定效应：先展示什么价格，会影响对方怎么评价后面的价格。
- 按价值定价，而不是按成本或时间定价。

## 推荐阅读

- Alex Osterwalder 等《价值主张设计》（Value Proposition Design）
- Alex Hormozi《$100M Offers》
- Madhavan Ramanujam《Monetizing Innovation》（选读：定价）

## 练习题

1. 为你的一个产品/服务画价值主张画布，标出最强的 3 个契合点。
2. 用价值方程拆解一个你觉得"很划算"的产品，说明它在四个变量上分别做了什么。
3. 为你自己的一项技能设计一个完整报价：交付什么、多少钱、多快、有什么保证、为什么现在买。
4. 找 3 个同类服务的定价页，分析它们用了哪些定价心理技巧。

## 通关标准

- [ ] 能用价值方程诊断一个报价的弱点并提出改进。
- [ ] 为自己设计一个报价，并真的拿给至少 2 个潜在客户看，记录反应。
