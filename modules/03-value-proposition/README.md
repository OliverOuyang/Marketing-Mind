# 03 · 价值主张与报价

> 核心问题：怎么让"选我"成为一笔显而易见的好交易？

## 学习目标

学完这个模块，你应该能：

1. 用价值主张画布把"用户的任务、痛点、收益"和"我的产品/能力"一一对上，并指出哪些对不上。
2. 用价值方程诊断任何一个报价，说出它最弱的变量是哪个。
3. 设计一个让人难以拒绝的报价（Offer）：交付物、价格、保证、附加价值、紧迫性。
4. 给自己的时间和技能定价，并能讲清楚"为什么是这个价"。

## 核心概念

### 1. 价值主张不是口号，是一笔交易的说明书

"专业、高效、用心"不是价值主张，因为任何人都可以这么说。价值主张要回答三个问题：

- **给谁**：哪个具体的人群（来自 02 定位）。
- **帮他完成什么任务**：功能、情感、社会三层（来自 01 JTBD）。
- **为什么是我而不是替代方案**：替代方案包括竞品、自己动手、什么都不做。

> 例：Superhuman 早期的价值主张不是"更好的邮箱"，而是"每天处理邮件的时间砍半，回到收件箱清零"。目标用户（创业者、VC）每天在邮件里泡 3 小时，30 美元/月对他们是小钱。

### 2. 用户买的是"结果"，付的是"总成本"

00 模块讲过：交换发生的条件是感知价值 > 感知成本。报价设计就是在这道不等式两边同时动手。

很多新人报价只做一件事：降价。但降价只动了"钱"这一项成本，还顺带拉低了感知价值。更好的做法往往是：

- 降低**风险**成本：保证、试用、分阶段付款。
- 降低**时间/精力**成本：替对方做更多，减少沟通轮次。
- 提高**确定性**：案例、数据、可验证的过往结果。

### 3. 报价 ≠ 价格

报价（Offer）是一个组合：**交付什么 + 多少钱 + 多久 + 有什么保证 + 附送什么 + 为什么现在**。同样 3000 元，"做一个网站"和"7 天上线、包 2 次修改、不满意退一半、送 3 个月维护"是完全不同的报价。

### 4. 价格本身就是信号

- 价格是定位的一部分。太便宜会让人怀疑质量，尤其在对方无法事先判断质量的服务上。
- **锚定**：对方看到的第一个数字会成为参照。先展示高档方案，中档方案显得合理。
- **诱饵效应**：《经济学人》的经典订阅页：电子版 59 美元、纸质版 125 美元、纸质+电子 125 美元。没人买中间那个，但它让第三个看起来"白送一份电子版"。
- 按**价值**定价，而不是按成本或工时。对方关心的是这件事帮他赚了/省了多少，不是你花了几个小时。

## 核心框架

### 价值主张画布（Strategyzer）

| 用户侧（圆） | 我方侧（方） |
|---|---|
| 任务（Jobs）：要完成什么 | 产品与服务：我提供什么 |
| 痛点（Pains）：阻碍、风险、烦恼 | 止痛药（Pain relievers）：怎么消除痛点 |
| 收益（Gains）：想要的结果和惊喜 | 增益器（Gain creators）：怎么创造收益 |

**用法**：

1. 先只画用户侧，并按重要性排序。用户侧必须有证据（访谈原话、差评原话），不能凭想象。
2. 再画我方侧，每一项都要能连线到用户侧的某一项。
3. 连不上的我方项 = 自嗨功能，砍掉或别拿出来讲。
4. 用户侧排名前三却没被覆盖的项 = 机会或风险。

### 价值方程（Alex Hormozi《$100M Offers》）

```
感知价值 = （梦想结果 × 实现可能性）÷（等待时间 × 付出努力）
```

| 变量 | 往哪个方向动 | 常见手段 |
|---|---|---|
| 梦想结果 | ↑ | 说清最终结果，而不是过程（"拿到 offer"而不是"改简历"） |
| 实现可能性 | ↑ | 案例、数据、保证、权威背书、免费试用 |
| 等待时间 | ↓ | 快速见效的第一步、明确交付时间 |
| 付出努力 | ↓ | 模板、代办、一对一、减少对方要做的事 |

分母比分子更容易优化：让结果更快、更省力，往往比承诺更大的结果更可信。

### 报价设计五件套

| 组件 | 问自己 | 例子（给小餐馆拍探店视频） |
|---|---|---|
| 核心交付 | 对方最终拿到什么结果？ | 3 条 15 秒探店视频，可直接发抖音 |
| 价格与档位 | 有没有锚点？有没有选择？ | 基础 1200 / 标准 2000 / 包月 6000 |
| 保证（风险逆转） | 对方最怕什么？我能承担哪部分风险？ | 首条不满意免费重拍 |
| 附加价值 | 什么对我成本低、对对方价值高？ | 送一份"店内拍照角落"布置建议 |
| 紧迫性/稀缺性 | 为什么现在？（必须真实） | 每月只接 4 家，本月剩 1 个名额 |

### 给自己的技能定价：三个参照

1. **市场参照**：同类服务的价格区间（去接单平台、同行主页看 10 个报价）。
2. **价值参照**：这件事对对方值多少（多带来多少客人、省多少人力）。目标拿到其中的 10%–20%。
3. **底线参照**：低于多少你会不想做、做不好。这是你的保留价，和 07 模块的 BATNA 相通。

## 案例速读

- **Dollar Shave Club**：剃须刀不是新东西，报价才是。每月 1 美元起、送上门、随时取消，把"去超市买贵刀片"的痛点（价格、麻烦、柜台锁着）全部对上。
- **Zappos 365 天免费退货**：网上买鞋最大的成本是"不合脚的风险"，它直接把风险全接过来，退货率上升，但转化和复购涨得更多。
- **求职场景**：一个设计实习申请者在邮件里附上"我为贵司 App 重做的注册页，3 张图"，就是在用作品把"实现可能性"拉满，同时让面试官"付出的努力"降到看三张图。

## 推荐阅读

- Alex Osterwalder 等《价值主张设计》（Value Proposition Design）：画布的原典，配图多，翻着看。
- Alex Hormozi《$100M Offers》：价值方程和报价设计，读前 8 章即可。
- Dan Ariely《怪诞行为学》（Predictably Irrational）：第 1 章讲锚定和诱饵效应。
- Madhavan Ramanujam《Monetizing Innovation》（选读）：先定价再做产品的思路。

## 练习题

1. **画布**：为你的一个产品/服务（或你本人）画价值主张画布。用户侧至少附 3 句真实原话；标出最强的 3 个契合点和 1 个"自嗨项"。
2. **方程拆解**：用价值方程拆解一个你觉得"很划算"的产品，逐个变量说明它做了什么。再找一个你没买的产品，指出它最弱的变量。
3. **报价设计**：为你自己的一项技能写出完整的报价五件套。
   - 加难度：预算减半的客户也要能下单，但你不能降价，只能调整交付或档位。
4. **定价页拆解**：找 3 个同类服务/SaaS 的定价页，各找出至少 2 个定价心理技巧（锚定、诱饵、免费档、年付折扣、推荐标签……）。
5. **真实报价**：把第 3 题的报价拿给至少 2 个潜在客户看（或在一个平台公开发布），记录对方第一反应和追问的问题。

## 通关标准

- [ ] 能用价值方程诊断一个报价的最弱变量，并提出两个不降价的改进办法。
- [ ] 为自己设计一个完整报价（五件套齐全），并真的拿给至少 2 个潜在客户看过，有反应记录。
- [ ] 能用一句话解释"为什么这个价"，且理由来自价值或市场，而不是"我花了多少时间"。
