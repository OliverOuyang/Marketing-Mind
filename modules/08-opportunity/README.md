# 08 · 机会捕捉

> 核心问题：机会从哪里来？怎么比别人早一步看见、更快一步验证、敢于小成本下注？

> 状态：骨架。学到这里时和导师一起补全细节。这个模块会贯穿整个学习过程：从第一天起就可以往 `opportunities/` 里记录机会。

## 学习目标

1. 知道机会通常来自哪几类"变化"，建立日常的信号扫描习惯。
2. 用一套快速评估方法判断一个机会值不值得投入。
3. 用最小可行实验（MVP / 冒烟测试）低成本验证机会。
4. 理解"运气表面积"：通过行动和曝光增加遇到好机会的概率。

## 核心框架

### 机会的七个来源（德鲁克《创新与企业家精神》）

1. 意外事件（意外的成功或失败）
2. 不协调（现实与预期不符）
3. 流程需求（某个环节明显很别扭）
4. 产业和市场结构变化
5. 人口结构变化
6. 认知、意义和情绪的变化
7. 新知识（新技术）

前四个在行业内部，后三个在外部。**越靠前的越容易、风险越低**。

### 运气表面积（Luck Surface Area）

```
运气 ≈ 做的事 × 让多少人知道你在做
```

你越多地做事，并公开分享，就越可能被机会撞上。这就是 06 模块"公开创作"的意义。

### 机会快速评估（每个维度 1–5 分）

| 维度 | 问题 |
|---|---|
| 痛点强度 | 有人正在为这个问题花钱/花时间吗？ |
| 时机 | 为什么是现在？发生了什么变化？ |
| 我的优势 | 我有什么别人没有的（技能、渠道、信息、关系）？ |
| 验证成本 | 最小验证要花多少时间和钱？ |
| 下行风险 | 最坏情况下我会损失什么？ |

高痛点 + 有时机 + 低验证成本 + 下行可控 → 立刻小成本试。具体填写用 `templates/opportunity-card.md`。

### 最小验证的几种方式

- **冒烟测试**：先做一个落地页/一条帖子描述服务，看多少人想要，再决定做不做。
- **人工替代**：先手动提供服务，验证需求后再产品化。
- **预售**：先收定金，用真实付款验证需求。

## 推荐阅读

- 彼得·德鲁克《创新与企业家精神》：第 3–9 章，七个来源。
- Eric Ries《精益创业》（The Lean Startup）：MVP 和"构建-测量-学习"。
- Nassim Taleb《反脆弱》：选读，"有限下行、无限上行"的下注思维。

## 练习题

1. **信号日记**：连续 2 周，每天记录 1 个你观察到的"变化"或"别扭"，标注属于七个来源中的哪一个。
2. **机会卡片**：从信号日记里挑 3 个最有意思的，填完整的机会卡片并打分。
3. **冒烟测试**：对得分最高的那个机会，设计并执行一个成本 ≤ 100 元、时间 ≤ 1 周的验证。
4. **复盘错过的机会**：回想一个你曾经看到但没抓住的机会，复盘当时为什么没动手。
