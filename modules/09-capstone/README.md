# 09 · 综合实战

> 核心问题：拿一个真实的东西，从 0 把它卖出去。

> 状态：骨架。完成 00–08 中至少 6 个模块后开始，也可以更早选题、边学边做。

## 目标

选择一个**真实对象**，完整走一遍营销链路，产出可以衡量的结果。

可选的实战对象：

- **你自己**：拿到一份理想的实习/工作/合作。
- **你做的一个东西**：作品、工具、课程、服务，拿到第一批真实用户或第一笔收入。
- **一个你发现的机会**：从 `opportunities/` 里选一张高分卡片，把它做起来。

## 实战流程

| 阶段 | 对应模块 | 产出 |
|---|---|---|
| 1. 洞察 | 01 | 至少 5 次用户访谈记录 + JTBD 任务陈述 |
| 2. 定位 | 02 | 定位陈述，通过一句话测试 |
| 3. 报价 | 03 | 完整的报价设计 |
| 4. 表达 | 04 | 落地页/简介/作品集/推广文案 |
| 5. 触达 | 05、06 | 渠道实验计划与数据 |
| 6. 成交 | 07 | 成交或谈判记录 |
| 7. 复盘 | 全部 | 一份完整的项目复盘，放进 `cases/` |

## 成功标准

在开始前，先写下一个可衡量的目标（例如"4 周内拿到 3 个付费客户"或"拿到 2 个目标公司的面试"），结束时对照复盘。

## 实战记录

每一轮实战在本目录下建一个子文件夹，例如 `09-capstone/2026-11-personal-brand/`，里面放计划、过程记录和最终复盘。
