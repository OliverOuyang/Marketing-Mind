# 案例库

用 [`templates/case-study.md`](../templates/case-study.md) 拆解案例，文件命名为 `YYYY-MM-DD-案例简称.md`。

选案例的建议：

- 让你"忍不住点开/想买"的东西，比教科书经典案例更有价值。
- 失败案例同样重要：一个营销翻车，往往比成功更能说明问题。
- 也拆"人"：某个人为什么突然火了、为什么拿到了那个机会。
