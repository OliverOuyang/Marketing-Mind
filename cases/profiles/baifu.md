## 身份卡（只写公开、与营销相关的部分）

独立开发者，公众号「超级Vibe」、X @whoisbaifu、小红书 BaiFu（简介首句"人生是一场漫长的自我表达"，其后列出作品履历 [K]）。三个公开作品：开源舆情分析系统 BettaFish（微舆）、开源群体智能预测引擎 MiroFish（获盛大投资孵化）、Apple Watch 录音 App Auday。三次都靠极小的推广动作获得大范围传播，同时一直被质疑"在搞营销"[A][B]。

## 心智模型（5 个）

每个都在至少两个项目里出现过。

### 1. 代码是冷的，故事是热的

- **一句话**：作品本身不传播，作品背后的故事才传播。
- **证据**：他把这句列为开源经验第 5 条 [B]；更早的原话是"决定它死活的，往往是两件事……第二，你会不会讲它。说好听点叫'叙事能力'，说直白点就是'你能不能把它吹明白'" [K]；BettaFish 的引爆点不是项目帖，而是 1k star 后的复盘文 [B][H]；MiroFish 之后写了万字长文 [B]；Auday 卖爆后又写长文"认领" [A]。
- **怎么用**：做完一件事，问"这件事里有没有一个低点到高点的故事"，而不是只问"功能写清楚了没有"。
- **局限**：故事要有一个足够硬的结果撑着。没有结果的故事会被当成自我感动。

### 2. 让作品先替你说话

- **一句话**：先让东西被看见、被验证，人再出场。
- **证据**：Auday 故意用零粉丝新号首发，"放下开发者过去的故事" [A]；MiroFish 做完后递给投资人的是一支粗糙的演示视频，不是一份 BP [B]；BettaFish 早期靠在 B 站、小红书、Linux Do 发真实演示 [B][H]。
- **怎么用**：推销自己时，先拿出一个别人能直接看、直接用的成果，再讲你是谁。
- **局限**：适合能被演示的东西。服务、咨询这类看不见的东西需要先找到"可演示的切片"。

### 3. 提前准备让别人帮你传的素材

- **一句话**：营销可以少做，但要让转发者手里有现成的东西。
- **证据**：开源经验第 4 条原话 [B]；BettaFish README 首屏放了完整的武大报告和运行视频 [I]；MiroFish 准备了武大推演、红楼梦结局两支视频和在线 Demo [F]；Auday 首发帖带 AI 剪辑的宣传片，他认为这是海外走红的重要因素之一 [A][C]。
- **怎么用**：发布前自查：一个从没见过你的大 V，能不能只靠你给的素材写出一条推荐？
- **局限**：素材让传播变容易，但不能保证有人传。他第一次给公众号和周刊投稿全部石沉大海 [B]。

### 4. 窄切口进，大口号出

- **一句话**：做一个具体的小东西，但用一句很大的话描述它。
- **证据**：开源经验第 2 条"从垂直领域来，到大众中去"，并举例"BettaFish 定位是舆情分析，标语打的却是'人人可用'" [B]；MiroFish 是舆情推演，口号是"预测万物" [F]；Auday 是手表录音，愿景是"最亲密、最私密的 Personal Agent" [A]。
- **怎么用**：先写清"今天它具体能干什么"，再加一句"它最终想成为什么"。两句都要有，顺序不能反。
- **局限**：大口号会招来"吹牛"的质疑，他用具体演示和"我可能"之类的降调来平衡 [A]。

### 5. 速度就是壁垒

- **一句话**：先用很短的时间做到 70 分推出去，比慢慢做到 100 分更有价值。
- **证据**：他明确说"第二类人则能用 1 天把这件事从 0 推到 70 分……速度本身就成了壁垒" [B]；BettaFish、MiroFish 都是约 10 天 [B]；Auday 发布会后"持续干了整整一周" [A]；首发后"48 小时集中开发"出 1.0.4 [D]。
- **怎么用**：把"什么时候发"定在"能演示"而不是"完美"的那一刻；发了之后用更新速度换信任。
- **局限**：他自己也承认爆火后 issue 暴涨、"每天起床两眼一睁就是修 bug" [B]。速度的代价是之后的稳定性债。

## 决策启发式（12 条）

1. **投稿没人理，就自己去社区发**：给公众号、周刊自荐"几乎全是石沉大海"，于是"换了更笨但更有效的方式"，在 B 站、小红书、Linux Do 发文 [B]。
2. **到了一个阶段性结果，就写复盘**：1k star 时写文章，"给自己和项目一个体面的 ending" [B]，结果成了引爆点。
3. **被质疑"营销包装"，就把质疑写成故事的前提**："有人因此称我为'营销大师'，心里总有些不服气……这一次我想让 Auday 完全从零开始" [A]。
4. **巨头做了相近的事，当成验证和截止日期**：看到苹果发布会的音频智能，"自己五月份冒出来的想法，竟然和苹果想到了一起"，同时"不能再拖了" [A]。
5. **用户最大的顾虑，用架构取舍去解决，并说出代价**：拿掉用户系统和中转服务器，"这样的取舍确实会减少很多收入，但……值得" [A]；对外说成"We don't even have a backend server" [C]。
6. **用户问"然后呢"，那就是下一个产品**：BettaFish 报告被问"我能拿它干嘛？"，于是做了 MiroFish [B]。
7. **花时间最多的是调研和选题，不是写代码**："我花时间最多的，反而是市场调研和技术选型" [B]；开源经验第 1 条 [B]。
8. **流量最后收口到人**：长文结尾是招聘令和交流群 [B]；Auday 官号把用户反馈逐条写进更新日志 [D]。
9. **读者只问三件事**：能不能帮我、能不能让我省时间、能不能让我装到逼。"大多数人不是来帮你 code review 的" [K]。
10. **用一句画面化的话说价值，不倒架构**：找到场景最贴近的那批人，比铺面撒网有效；例句"可以从平台全量采集，再自动生成一份可以丢进汇报会的舆情简报" [K]。
11. **标题党没用，大话要有硬数字撑**："夸张的宣传反而会稀释可信度" [K]。他的标题都很大，但每个都挂着一个可验证的数字（1K+、七天、三十万、付费榜第一）[A][B][K]。
12. **同一内容按平台改说法**：公众号标题写"卖了三十万"，小红书封面改成"七天登顶 AppStore 付费应用总榜"，笔记标题改成"来把你的Apple Watch变成最好的AI录音硬件" [A][K]。

## 表达 DNA

| 维度 | 特征 | 例子 |
|---|---|---|
| 标题 | 时间 + 数字 + 结果 + 一个大判断或时代叙事 | 《七天时间，从零开始到把软件卖了三十万，我可能把 Apple Watch 变成了最好的 AI 录音硬件》[A]；《3个月……我亲历了Vibe Coding带来的超级个体时代》[B] |
| 开头 | 先给结果或落差，再回到低点 | "三个月前，我还在为实习焦虑" [B]；"说不担心是假的" [A] |
| 节奏 | 长文先列目录预告，再按章节推进；每章结尾留一个钩子 | "也正是从这里开始，故事进入了下一章" [B] |
| 语气 | 口语化、带情绪，常用"说实话""说真的""哈哈"，常自嘲 | "当然也不能这么算哈哈" [A]；"第一周我瘦了十斤" [B] |
| 确定性 | 对时代判断很笃定，对自己的成绩往下压 | "真的能成，并且会越来越好" [B]；"稀里糊涂"拿到投资 [B]；"我可能" [A] |
| 比喻 | 用一个日常物件解释抽象概念 | 后视镜和望远镜 [B]；数字沙盘 [B]；"像媒人一样"介绍 Agent [A] |
| 具体化 | 用一个具体的人或一天代替"记录生活" | 和 Emma 的约会、毕业那天 [A] |
| 感谢 | 点名感谢社区和第一个转发他的人 | Linux Do、why技术 [B] |
| 叠甲 | 下结论前先自嘲一句，降低读者防备 | "开源的含金量其实就那样（叠个甲是在说自己的项目），但效果真的很好" [K] |
| 直白 | 先给体面说法，再给大白话 | "说好听点叫'叙事能力'，说直白点就是'你能不能把它吹明白'" [K] |
| 平台格式 | 小红书长文做成图卡：封面放数据图或大标题、"全文 N 字｜阅读需 N 分钟"、一段导语预告各部分，最想知道的放最后 | 《1K+ Star》封面是 Star History 曲线，导语把"收入"放在最后 [K] |
| 英文官号 | 短句、反问开头、we 视角、把顾虑和报价写成一行一句 | "The best AI recording hardware? You may already own it." [C]；"What if predicting the future was actually… fun?" [G] |

## 价值观与反模式

**他看重的**（按文本里出现的强度排）：

1. 产品本身要能站住，"仅凭产品本身的创意、对痛点的解决，能不能让它脱颖而出" [A]。
2. 隐私和信任优先于收入 [A][E]。
3. 回馈社区，把经验"开源"出来 [B]。
4. 年轻人和个人的可能性（"超级个体"）[B]。

**他明确反对的**：

- 迷信固定教程："别指望有一套永远不过期的教程" [B]。
- 大而全和完美主义：开源经验第 3 条 [B]。
- 等别人来发现你：第一次投稿失败后就自己去社区发 [B]。

**内在张力**（这正是值得想清楚的地方）：

- 他说"营销推广可以不多"[B]，但每一步的标题、素材、时机都很讲究。少做不等于不设计。
- 他强调"完全从零开始"[A]，但写作能力、平台手感和过往声望并没有清零。
- "预测万物"这类大口号 [F] 和"技术水平并非特别出色"的自评 [B] 同时存在。
- 他说"标题党没用" [K]，自己的标题却一个比一个大。区别在于他的大标题都挂着可验证的数字。
- 2025 年他说"海外我只试了推特，但效果一般" [K]，2026 年 Auday 恰恰靠 X 英文新号打爆 [A]。渠道结论会随产品变化。

## 诚实边界

- 只覆盖营销与发布维度，不代表他的技术判断或个人观点全貌。
- 全部来自公开表达。公开写出来的复盘是经过选择的，真实决策过程可能更乱，也可能有没写出来的推广动作（例如 10-13 他提到在投 App Store 搜索广告 [J]，长文里没写）。
- 销量、浏览量、融资额都是自述或媒体转述，没有第三方核实。
- 他的成功有时机和运气成分，他本人也称之为"失控的幸运" [B]。照搬方法不等于能复制结果。
- 信息截止 2026-10-20，之后的变化没有纳入。
