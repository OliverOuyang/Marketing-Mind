## 发布顺序（默认）

1. 仓库内容定稿：首屏钩子、示范稿、至少两个爆款拆解（BaiFu、小王子）。
2. 长文首发，讲"做游戏没人看 → 拆爆款 → 做成 skill"的故事，结尾引到仓库。
3. 同一天发 X 推文串和小红书图卡，按平台改说法，不复制粘贴。
4. 出现阶段性结果（Star 数、第一个外部 PR、有人用 skill 写出的稿子）就写复盘。

写之前先在 [skills/marketing-mind/references/writing.md](../skills/marketing-mind/references/writing.md) 里对照结构，交付时附五个检验自检表。
