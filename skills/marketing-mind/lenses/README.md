# 案例镜头（lenses）

一个镜头 = 一位创作者经过公开验证的营销打法，浓缩成可以直接调用的规则。用户说"用 X 的方法写""像 X 那样发布"时，在对应模式（写作、运营、视频）的通用结构上，叠加这个镜头的规则。

**镜头不是模仿对象。** 只借结构和判断，不借身份、经历、数据、原句和口头禅；产出仍然以用户自己的身份和素材为准。

## 怎么加一个新镜头

1. 先按 [references/teardown.md](../references/teardown.md) 拆这个人，画像放 `cases/profiles/<人名>.md`，每条判断都要有公开出处。
2. 新建 `lenses/<人名>.md`，固定五节：**什么时候用这个镜头**、**核心打法（3–5 条，带出处代号）**、**表达特征**、**和通用结构的差异**（只写叠加或替换的部分）、**不适用的情况**。
3. 在上表登记一行。

镜头文件保持在 3 KB 左右，细节和证据留在画像里。
