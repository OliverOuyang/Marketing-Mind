# 拆解模式：拆案例、拆人

目标不是写一篇读后感，而是拿走一招能用在自己身上的东西。

## 拆一个案例（一次发布、一条爆文、一个广告）

1. **先收集一手材料**：原帖、原文、商店页、README、作者本人的复盘。公众号和 X 帖子通常能抓到全文；视频看不了时说明，只拆能读到的部分。转述和媒体报道标为二手。
2. **记第一反应**：看到它想点开、想买、无感还是反感？先写下来，再分析为什么。
3. **沿营销链路拆**，每环打 1–5 分：

| 环节 | 问题 | 对应模块 |
|---|---|---|
| 洞察 | 目标用户是谁，要完成什么任务？ | 01 |
| 定位 | 占了什么心智格子？和谁区分开？ | 02 |
| 价值主张/报价 | 为什么是好交易？ | 03 |
| 表达 | 用了什么结构和说服原则？标题、开头、证据怎么写的？ | 04 |
| 触达 | 在哪些渠道出现？先后顺序？为什么选这里？ | 05、06 |
| 转化 | 怎么推动行动？ | 07 |

4. **最关键的一招**：只能学一件事，是什么？
5. **如果我来做**：保留什么、改什么、它的风险或盲区。
6. **迁移**：写出一个用户自己明天就能做的具体动作。

模板：`templates/case-study.md`。成稿放 `cases/YYYY-MM-DD-案例简称.md`，并更新 `cases/README.md` 索引；看到的好标题、好句子顺手收进 `swipe-file/`。

## 拆一个人（为什么他总能火）

参照 [女娲.skill](https://github.com/alchaincyf/nuwa-skill) 的蒸馏结构，只拆营销与发布这一个维度，"捕捉他怎么想，不是他说了什么"：

1. **来源代号表**：每条来源一个字母代号，写清标题、日期、链接。只用本人公开发表的内容和公开报道，不收集私人信息。
2. **心智模型（3–5 个）**：每个至少在两个项目里出现过；写一句话、证据（带代号）、怎么用、局限。
3. **决策启发式（8–12 条）**：遇到什么情况他会怎么做，带原话和代号。
4. **表达 DNA**：标题、开头、节奏、语气、确定性、比喻、平台格式，各给一个原句例子。
5. **价值观与反模式**，以及**内在张力**（他说的和做的哪里不一致，这里最值得想清楚）。
6. **诚实边界**：公开复盘是被选择过的；销量和融资多为自述；有运气和时机成分；写明信息截止日期。

成稿放 `cases/profiles/<人名>.md`。拆完后，如果这个人的打法值得反复调用，按 [lenses/README.md](../lenses/README.md) 写一个案例镜头。

## 质量要求

- 每个判断后面挂出处代号或原文位置；推测要写"推测"。
- 数字区分"自述""媒体转述""第三方数据"。
- 至少写一条"这招在什么情况下不灵"。
