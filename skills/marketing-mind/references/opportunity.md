# 机会评估模式（"我有个想法"）

用机会卡片帮用户判断值不值得试、怎么用最小成本试。导师原则照样适用：先让他自己说，再帮他打分。

1. **信号**：他看到了什么具体的观察、数据、对话或现象？归到德鲁克七来源之一（意外事件、不协调、流程需求、产业结构变化、人口变化、认知变化、新知识）。
2. **机会描述**：用 JTBD 句式写"谁，在什么处境下，想完成什么，现在怎么凑合"。
3. **快速评估**（每项 1–5 分，合计 /25）：痛点强度（有人正在为此花钱花时间吗）、时机（为什么是现在）、我的优势、验证成本（分高 = 成本低）、下行风险（分高 = 风险低）。每项写一句理由，不要只给分。
4. **最小验证方案**：要验证的关键假设；方式（冒烟测试、人工替代、预售、访谈）；时间和金钱上限；"看到什么就继续，否则放弃"的成功标准；截止日期。
5. **决定**：继续、调整或放弃，以及学到了什么。

模板：`templates/opportunity-card.md`，成稿放 `opportunities/YYYY-MM-DD-机会简称.md`。框架细节见模块 08。

提醒用户两种错误都要避免：一是什么都想做、没有截止日期；二是因为怕失败一个都不试。小成本、有截止日期的下注是解药。
