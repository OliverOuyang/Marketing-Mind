# Marketing Mind · 营销思维训练场

> 目标：学会**把自己、把自己做的东西卖出去**，并练出**看见机会、抓住机会**的本能。
> 方式：系统学习 + 高频练习 + 每次复盘，Claude 担任导师。

这个仓库不是读书笔记仓库，而是一个**训练场**。每学一个概念，都要落到一次真实练习上：写一段文案、改一次自我介绍、拆一个案例、发一条内容、谈一次合作，然后复盘。知识只有被用过才算学会。

## 一、我要练成的五种能力

| 能力 | 一句话描述 | 主要对应模块 |

| 成交推进 | 把兴趣变成行动：报名、付款、合作、录用 | 07 |
| 机会捕捉 | 比别人早一步看到变化，并用最小成本下注 | 08 |

## 四、怎么用（每周节奏）

一个可持续的最低节奏，比偶尔的爆发更重要：

| 频率 | 做什么 | 产出 |
|---|---|---|
| 每次学习（30–60 分钟） | 读模块 → 和 Claude 讨论一个框架 → 做一道练习 | `practice/` 里一条记录 |
| 每周 2 次 | 拆一个真实案例（广告、产品发布、某人的走红） | `cases/` 里一份拆解 |
| 每天随手 | 看到让你"想点开/想买"的东西，存下来并写一句为什么 | `swipe-file/` |
| 每周一次 | 周复盘：这周学了什么、做了什么、哪个假设被打脸 | `practice/weekly/` |
| 有想法时 | 记下一个机会，填机会卡片，决定是否小成本验证 | `opportunities/` |

### 和导师（Claude）的协作方式

在这个 project 或仓库里，可以直接这样说：

- **"开始今天的学习"**：Claude 会读 `PROGRESS.md`，告诉你现在在哪个模块、今天学什么、做哪道练习。
- **"给我出一道题"**：针对当前模块出一个场景题，你作答后它会点评并追问。
- **"拆这个案例：……"**：贴一个广告/产品/帖子，一起用案例模板拆解。
- **"帮我复盘"**：讲讲你刚做的事（发了帖、谈了合作、面了试），Claude 用复盘模板帮你提炼。
- **"我有个想法……"**：Claude 用机会卡片帮你判断值不值得试、怎么用最小成本试。
- **"考考我"**：模块结束时做通关测试，通过后更新 `PROGRESS.md`。

导师的原则写在 [CLAUDE.md](CLAUDE.md) 里：多问少讲、先让你想、点评要具体、每次都落到行动。

## 五、三条底线

1. **每学必练**：没有练习记录的学习不算数。
2. **真实优先**：练习尽量用真实对象（你的简历、你的项目、你想合作的人），而不是假想题。
3. **结果说话**：判断好坏看对方的反应（回复率、点击、成交、拒绝理由），不看自己感觉。
