# 机会池

用 [`templates/opportunity-card.md`](../templates/opportunity-card.md) 记录你发现的机会，文件命名为 `YYYY-MM-DD-机会简称.md`。

原则：

- **先记下来再判断**。机会往往在你觉得"这好像有点意思"的时候出现，过几天就忘了。
- **小成本验证**。高分机会立刻设计一个一周内、低成本的验证实验。
- **放弃也是结果**。验证后放弃的卡片保留，标记"已放弃"并写下原因，它们是你判断力的训练数据。
